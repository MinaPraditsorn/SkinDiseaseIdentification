Distance (Hamming distance) คือจำนวน feature ที่ไม่ตรงกันจากทั้งหมด 11 ข้อ distance 0 แปลว่าเหมือนกันทุกข้อ โมเดลเรียงรูปใน training set จาก distance น้อยไปมาก เอา 5 รูปแรก (5 nearest neighbors) มา vote โรคที่ได้ vote มากสุดคือ prediction

ถ้ามีรูป distance เท่ากันเกิน 5 รูป จะเลือกรูปที่อยู่ลำดับก่อนในไฟล์ ถ้า vote เสมอ จะเลือกโรคที่ผลรวม distance น้อยกว่า และถ้ายังเสมออีก จะเลือกโรคของ nearest neighbor ตัวแรก กติกาแตกเสมอนี้อาจต่างจาก scikit-learn ในกรณีที่เลือก feature แปลกๆ แต่ให้ผลตรงกันกับ test set ทั้ง 9 รูป
